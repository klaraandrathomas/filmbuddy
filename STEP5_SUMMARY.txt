FUZZY MATCHING STRATEGY:
  1. Extract key dialogue (first, last, middle lines)
  2. Normalize text (lowercase, no punctuation)
  3. Search subtitles with rapidfuzz
  4. Score matches (0-1 confidence)
  5. Select best match above threshold (0.75)
  6. Apply ±5-15s buffer

INTERPOLATION STRATEGY:
  - If previous scene has timestamp → start after it
  - Otherwise → proportional estimate based on position
  - Scene duration → average or 60-180s range
  - Mark with 0.30 confidence

CONFIDENCE SCORING:
  0.90-1.00 → Exact/near-exact dialogue match
  0.75-0.89 → Good match with minor differences
  0.30      → Interpolated estimate (low confidence)

EDGE CASES HANDLED:
  ✓ Action-only scenes (no dialogue)
  ✓ Short dialogue (< 4 words, skipped)
  ✓ First/last scenes (boundary handling)
  ✓ Similar dialogue (best match wins)
  ✓ Different script versions (adjustable threshold)
