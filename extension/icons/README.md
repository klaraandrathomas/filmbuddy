# Extension Icons

You need to create PNG icons for the extension:

- `icon16.png` - 16x16 pixels (toolbar)
- `icon48.png` - 48x48 pixels (extensions page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Quick Option: Create Simple Icons

You can create these using any image editor or online tool. Here's a simple approach:

1. Create a 128x128 canvas with background color `#6366f1`
2. Add the text "FB" in white
3. Export as PNG at 128x128, 48x48, and 16x16

## Or Use a Placeholder

For development, you can use any small PNG image renamed to these filenames.
The extension will work without proper icons, but Chrome will show a default icon.
