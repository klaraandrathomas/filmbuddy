INPUT FORMAT: Plain Text (.txt)
  • Scene headers: ALL CAPS, starts with INT./EXT.
  • Character names: ALL CAPS, centered (10+ spaces)
  • Dialogue: Regular text after character names
  • Action: Left-aligned description
  • Parentheticals: (in parentheses)

OUTPUT FORMAT: Structured Scene Dictionaries
  • scene_id, scene_header, location, time_of_day
  • int_ext (INT/EXT/INT/EXT)
  • characters (list of speakers)
  • dialogue (list with character, text, parenthetical)
  • action_lines (list of descriptions)
  • raw_text (original scene text)

USAGE EXAMPLE:

    from preprocessing.script_parser import ScriptParser
    
    # Read screenplay
    with open("scripts/lalaland.txt", "r") as f:
        script_text = f.read()
    
    # Parse into scenes
    parser = ScriptParser()
    scenes = parser.parse_script(script_text)
    
    # Access structured data
    for scene in scenes:
        print(f"Scene {scene['scene_id']}: {scene['location']}")
        print(f"  Characters: {', '.join(scene['characters'])}")
